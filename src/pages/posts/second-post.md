## Hướng dẫn cách hack sóng wifi với linux/temux(android)

### Bước 1: Mở teminal trong linux lên
### Bước 2: Thực hiện các câu lệnh 
- git clone https://github.com/3xploitGuy/lazyaircrack.git
- cd lazyaircrack
- chmod +x lazyaircrack.sh
- sudo ./lazyaircrack.sh (câu lệnh này để chạy)
#### Note: Nếu chưa cài git, tiến hành cài bằng câu lệnh #sudo install git

### Bước 3: Tiến hành phá sóng

![alt text](/assets/images/hackwifi.png 'Logo Title Text 1')
- Chọn option 2(Vì option 1 yêu cầu router)
- Sau khi chọn xong thì nó sẽ scan wifi gần đó ra 1 list 
- Chọn wifi và tiến hành DDOS
