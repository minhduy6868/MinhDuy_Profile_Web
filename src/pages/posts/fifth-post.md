## Hướng dẫn cách deploy website lên Internet miễn phí 
Trong thời đại công nghệ số hiện nay, việc xây dựng và triển khai một trang web trở nên dễ dàng hơn bao giờ hết. Nhiều nền tảng cung cấp dịch vụ deploy website miễn phí, giúp người dùng có thể chia sẻ dự án của mình với thế giới mà không cần đầu tư chi phí lớn. Việc deploy không chỉ giúp bạn giới thiệu sản phẩm, dịch vụ, hay ý tưởng của mình mà còn là cơ hội để học hỏi và phát triển kỹ năng lập trình.

### Các nền tảng phổ biến cho việc deploy miễn phí
#### GitHub Pages: 
Đây là một lựa chọn tuyệt vời cho những ai đã quen thuộc với Git và GitHub. GitHub Pages cho phép bạn dễ dàng triển khai trang web tĩnh chỉ với vài bước đơn giản. Bạn chỉ cần tạo một repository, tải mã nguồn lên và kích hoạt tính năng GitHub Pages để có được địa chỉ trang web của riêng mình.

#### Netlify:
 Netlify cung cấp một quy trình deploy dễ dàng với khả năng tự động hóa cao. Bạn có thể kết nối với repository GitHub của mình, hoặc đơn giản chỉ cần kéo và thả thư mục chứa mã nguồn lên Netlify. Nền tảng này cũng hỗ trợ nhiều tính năng như cấu hình tên miền tùy chỉnh và chức năng tự động deploy khi có thay đổi trong mã nguồn.

#### Vercel:
 Được biết đến với sự tối ưu cho các ứng dụng JavaScript, Vercel cũng là một lựa chọn lý tưởng để deploy website. Với quy trình thiết lập nhanh chóng và khả năng tự động nhận diện cấu trúc dự án, Vercel giúp bạn triển khai website chỉ với một vài cú nhấp chuột.

 ## Hướng dẫn chi tiểt
### 1. Sử dụng GitHub Pages
#### Bước 1: Tạo repository
Đăng nhập vào tài khoản GitHub.
Tạo một repository mới (nên đặt tên là username.github.io).
#### Bước 2: Tải lên mã nguồn
Tải lên mã nguồn website của bạn vào repository.
#### Bước 3: Kích hoạt GitHub Pages
Vào tab Settings của repository.
Cuộn xuống phần GitHub Pages.
Chọn branch (thường là main hoặc master) và nhấn Save.
#### Bước 4: Truy cập website
Website của bạn sẽ có địa chỉ https://username.github.io.
### 2. Sử dụng Netlify
#### Bước 1: Đăng ký tài khoản
Truy cập Netlify và tạo tài khoản.
#### Bước 2: Tải lên mã nguồn
Nhấp vào New site from Git hoặc Deploy manually.
Nếu chọn Deploy manually, bạn có thể kéo và thả thư mục chứa mã nguồn website của mình.
#### Bước 3: Thiết lập
Làm theo hướng dẫn để cấu hình tên miền (Netlify sẽ cung cấp một tên miền miễn phí).
#### Bước 4: Truy cập website
Website của bạn sẽ có địa chỉ như https://your-site-name.netlify.app.
### 3. Sử dụng Vercel
#### Bước 1: Đăng ký tài khoản
Truy cập Vercel và tạo tài khoản.
#### Bước 2: Tải lên mã nguồn
Chọn New Project và kết nối với GitHub, GitLab hoặc Bitbucket.
Chọn repository chứa mã nguồn của bạn.
#### Bước 3: Thiết lập
Vercel sẽ tự động phát hiện cấu trúc dự án và cấu hình build cho bạn. Bạn chỉ cần nhấn Deploy.
#### Bước 4: Truy cập website
Website của bạn sẽ có địa chỉ như https://your-project-name.vercel.app.
